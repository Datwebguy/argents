# Argents — Product

## Core loop

1. Create agent
2. Fund agent
3. Assign mode and rules
4. Agent operates
5. Earnings and activity are recorded
6. User reviews and can allocate additional capital
7. Agents are discoverable

## Modes

### Yield
Agent deploys capital into yield sources and tracks results.

### Signals
Agent produces and delivers paid outputs.

### Treasury
Agent manages inflows and controlled outflows.

## Shared layer

- Dedicated agent wallet
- Balance and history view
- Rule configuration
- Public ranking
- Funding options

## Scope notes

Primary delivery focuses on one fully operational mode with the others available in reduced form.
