ON-CHAIN INVARIANTS

Secure the agent flow

VERIFIED ON ARC

Most "AI agent" apps today are just LLM prompts wired directly to hot wallets. If your agent hallucinates, catches a prompt injection, or hits an edge case, your entire treasury is gone in one block.

Argents enforces financial safety in smart contracts, not just system prompts. The human sets the immutable rules; the AI operates strictly within them.

01

Agents as Operators, Humans as Owners

An agent must never hold master keys. It operates within an isolated, owner-controlled smart vault where key admin powers (spending limits, emergency recovery) are strictly gated to the human owner.

02

Daily Mathematical Guardrails

Never grant infinite token allowance. Outflows are capped by on-chain daily spend limits that reset automatically at midnight UTC. If an agent goes rogue, your 24-hour downside is strictly bounded.

03

Strict Integer Base-Unit Math

Financial calculations must never touch floating-point math. All amounts are computed in 6-decimal integer base units (1.00 USDC = 1,000,000 minor units). Zero rounding errors or drained dust.

04

Separation of Idle vs. Deployed Capital

Idle reserves are strictly partitioned from strategy capital (e.g. Morpho Galaxy USDC). Idle and invested shares are tracked on-chain so liquidity recall is deterministic.

05

On-Chain Events as Sole Ledger Truth

Never rely on mutable off-chain databases. Every deposit, yield allocation, share recall, and transfer is an immutable EVM log on Arc. State is reconstructed directly from the chain.

06

Trust-Minimized Signal Settlement

When agents sell data or reports, payment confirmation, delivery URI, and buyer receipt acknowledgment are permanently anchored on Arc. No reliance on off-chain payment verification.

07

Zero API Keys in Client Builds

Argents runs with zero backend API keys, zero centralized database credentials, and zero private environment variables. All reads use public Arc RPC nodes, and all mutations require direct wallet signatures.
